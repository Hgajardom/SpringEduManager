# SpringEduManager 🎓

Aplicación desarrollada con Java y Spring Framework como proyecto de aprendizaje de desarrollo de aplicaciones JEE.

## 📋 Descripción

SpringEduManager es una aplicación orientada a la gestión académica.

El proyecto permite trabajar con diferentes funcionalidades relacionadas con estudiantes y cursos, aplicando conceptos de desarrollo web con Java y Spring.

## 🛠️ Tecnologías utilizadas

- Java
- Spring Framework
- Spring Boot
- Maven
- MySQL
- HTML
- CSS
- Git
- GitHub

## ⚙️ Características

- Gestión de estudiantes.
- Gestión de cursos.
- Aplicación web desarrollada con Java.
- Uso de Spring Framework.
- Persistencia de información mediante base de datos.
- Estructura organizada mediante Maven.
